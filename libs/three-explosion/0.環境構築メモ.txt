2025.08.29 three.quarksというライブラリを使った3Dオブジェクトの爆発ライブラリの作成

## src/libQuarks.js #################################
このファイルが dist/explosion-bundle.js から公開される。

## src/main.js #################################
libQuarks.jsを利用するファイル、ライブラリ開発用で外部からは利用しない。

## npm run dev #################################
プロジェクトルートで、実行する。
開発用の実行環境

## npm run build #################################
プロジェクトルートで、実行する。
ロールアップしてライブラリファイルを作成する。
dist/explosion-bundle.js が作られる。

## 実行環境でのテスト #################################
test_library.html をプロジェクトルートに作成する。
プロジェクトルートで python -m http.server


ここからは環境構築
------------------------------------------------------------

## Viteプロジェクト作成 #################################
npm create vite@latest three-explosion
 (Vanilla, JavaScriptを選択)
cd three-explosion

## 依存関係インストール #################################
npm install three three.quarks

## vite.config.js #################################
プロジェクトルート(three-explosion)に以下の内容のvite.config.jsファイルを追加する。
import { defineConfig } from 'vite';
export default defineConfig({
  build: {
    lib: {
      entry: './src/explosion.js',
      fileName: 'explosion-bundle',
      formats: ['es']
    },
    rollupOptions: {
      output: {
        format: 'es'
      }
    },
    minify: false  // デバッグしやすくするため（本番では true）
  }
});
